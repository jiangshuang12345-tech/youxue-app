## 1. 需求背景

当前优学 App 内的音频资源缺少统一、直观的收听入口，用户需要在不同业务场景中寻找音频内容，难以形成稳定的日常收听习惯。同时，课内音频与早读、哄睡、磨耳朵、儿歌、故事等课外内容在使用目的上存在差异，需要通过分类和筛选帮助用户快速定位。

本需求在「优学中心」新增 FM 入口，并建设独立 FM 页面。用户可浏览音频、筛选年龄或级别、切换内容分类、查看字幕并完成播放控制。

本期对课内音频仅开放 L1、L2 两个级别，并完全沿用现有课内音频资源，不新增、不删除、不替换、不编辑既有资源内容。

## 2. 产品目标

1. 在优学中心提供清晰、稳定的 FM 入口，降低用户进入音频内容的操作成本。
2. 支持按年龄或级别进行互斥单选筛选，帮助用户快速找到合适内容。
3. 支持按内容分类浏览音频，其中课内音频仅展示 L1、L2 级别。
4. 提供完整的音频播放、暂停、进度调整、循环与字幕查看能力。
5. 保持既有课内音频资源和资源关系不变，仅增加 FM 侧的聚合展示与筛选能力。

## 3. 非目标

* 本期不新增、删除、替换或编辑现有课内音频资源。
* 本期不改变课内音频原有标题、封面、音频文件、字幕、级别、年龄、排序及上下架状态。
* 本期不建设音频上传、编辑、审核、付费或下载能力。
* 本期不新增播放列表、收藏、评论、分享、定时关闭、倍速播放及离线缓存能力。
* 本期不调整优学中心及底部三 Tab 的其他业务流程。
* 本期不扩展课内音频至 L3 及以上级别。

## 4. 用户角色与核心场景

### 4.1 用户角色

* 学生：选择适合自己的音频，进行磨耳朵、儿歌、故事或课内内容收听。
* 家长：根据孩子的年龄、级别和使用场景选择音频，并辅助孩子查看字幕。

### 4.2 核心场景

* 用户从优学中心快速进入 FM，继续收听或选择一条音频播放。
* 家长按孩子年龄或英语级别筛选内容。
* 用户按早读、哄睡、磨耳朵、唱儿歌、听故事、学英语、课内等分类浏览音频。
* 用户点击 Dino 区域显示或隐藏当前音频字幕。
* 用户播放、暂停、拖动进度或开启单曲循环。

## 6. 页面与功能需求

### 6.1 优学中心 FM 入口

| 模块 | 功能 | 描述 |
| --- | --- | --- |
| FM 入口 | 页面入口 | 在优学中心右上角增加「FM」入口，位置、尺寸、圆角及视觉样式以原型为准。 |
| 点击跳转 | 进入 FM | 点击 FM 入口进入 FM 首页；进入后不改变优学中心其他模块状态。 |
| 返回 | 返回优学中心 | FM 首页点击左上角返回按钮，返回优学中心；返回按钮箭头需在圆形按钮中水平、垂直居中。 |

### 6.2 FM 首页

| 模块 | 功能 | 描述 |
| --- | --- | --- |
| 页面标题 | FM | 页面顶部居中展示「FM」。 |
| 筛选入口 | 年龄/级别 | 默认展示「全部」；选择具体年龄或级别后，入口回填当前选中项。 |
| 分类入口 | 内容分类 | 默认展示「ALL」；点击后从底部打开分类抽屉。 |
| 音频列表 | 内容浏览 | 展示封面、标题、级别、年龄、播放量/收听量及播放状态，字段和布局以原型为准。 |
| Dino 区域 | 字幕开关 | 点击 Dino 区域显示或隐藏当前音频字幕。 |
| 底部播放器 | 播放控制 | 展示当前音频标题、当前时间、总时长、播放/暂停、进度条和单曲循环按钮。 |

### 6.3 音频列表

| 项目 | 规则 |
| --- | --- |
| 列表内容 | 按当前分类、筛选项及后台有效资源返回列表。 |
| 单条信息 | 展示封面、标题、级别、适龄范围、收听量和播放按钮。字段缺失时按第 8 章兜底。 |
| 默认状态 | 首条可按产品策略展示为当前音频；无历史播放记录时默认不自动播放。 |
| 点击播放 | 点击某条音频的播放按钮后，该音频成为当前音频并开始播放；其他音频停止。 |
| 当前播放态 | 当前条目展示播放中的视觉状态；底部播放器同步更新标题、时长和进度。 |
| 列表滚动 | 列表区域独立滚动；顶部筛选、分类入口及底部播放器位置保持稳定。 |
| 筛选更新 | 筛选或分类变化后刷新列表；若当前音频不在新结果内，允许继续播放，但取消列表内高亮。 |

### 6.4 年龄/级别筛选

#### 6.4.1 展示与关闭

| 项目 | 规则 |
| --- | --- |
| 默认值 | 默认选中「全部」，筛选入口显示「全部」。 |
| 打开 | 点击顶部筛选胶囊，在当前 FM 页面上动态展示真实筛选面板，不切换为带筛选框的背景图片。 |
| 维度切换 | 点击面板左侧「年龄」「级别」标签，手动切换对应选项。 |
| 关闭 | 再次点击筛选入口或点击面板外区域关闭；点击面板内部空白区域不关闭。 |
| 状态保留 | 面板关闭后保留当前选中项；再次打开时展示对应选中态。 |

#### 6.4.2 互斥单选规则

年龄和级别属于两个互斥筛选维度，全局最多保留一个具体筛选项。

| 用户操作 | 结果 |
| --- | --- |
| 选择具体年龄 | 选中该年龄；清除已选具体级别；顶部仅展示该年龄。 |
| 选择具体级别 | 选中该级别；清除已选具体年龄；顶部仅展示该级别。 |
| 选择「全部」 | 清除当前维度的具体选项；顶部恢复展示「全部」。 |
| 在同一维度选择新项 | 新选项替换旧选项，始终只有一个选中项。 |

#### 6.4.3 课内级别限制

| 场景 | 级别选项 | 说明 |
| --- | --- | --- |
| 分类为「课内」 | 全部、L1、L2 | 课内仅支持 L1、L2，不展示或返回 L3 及以上内容。 |
| 分类为「ALL」或其他非课内分类 | 沿用现有可用级别 | 不因本需求调整现有非课内资源的级别配置。 |
| 已选 L3 及以上后切换至「课内」 | 自动恢复为「全部」 | 清除不适用于课内的级别条件，刷新并展示全部课内音频。 |
| 通过异常参数请求课内 L3 及以上 | 返回空结果或按「全部」兜底 | 前后端均需校验，禁止展示不符合规则的课内资源。 |

### 6.5 分类抽屉

| 项目 | 规则 |
| --- | --- |
| 默认分类 | 默认选中「ALL」，顶部分类入口展示「ALL」。 |
| 打开方式 | 点击顶部「ALL/当前分类」胶囊，从页面底部打开分类抽屉并显示暗色蒙层。 |
| 分类项 | ALL、早读、哄睡、磨耳朵、唱儿歌、听故事、学英语、课内；名称及顺序以原型为准。 |
| 切换 | 点击分类项后更新当前分类、关闭抽屉并刷新音频列表。 |
| 选中态 | 当前分类在抽屉中展示明确选中态；再次打开时保留。 |
| 蒙层关闭 | 点击抽屉外暗色蒙层关闭抽屉；点击抽屉内部空白区域不关闭。 |
| 分类与筛选联动 | 切换至「课内」时执行课内级别校验；切出「课内」后不自动选择其他级别。 |

### 6.6 字幕交互

| 项目 | 规则 |
| --- | --- |
| 触发区域 | Dino 小恐龙及其提示区域，点击热区以原型为准。 |
| 默认状态 | 默认隐藏字幕。 |
| 显示字幕 | 点击 Dino 后显示当前音频字幕，并给出明确的显示状态反馈。 |
| 隐藏字幕 | 字幕显示时再次点击 Dino，隐藏字幕。 |
| 音频切换 | 切换音频后加载新音频字幕；若用户已打开字幕，则保持显示状态。 |
| 无字幕 | 资源无字幕时提示“该音频暂未提供字幕”，不展示空白字幕层，不影响播放。 |

### 6.7 音频播放

| 模块 | 规则 |
| --- | --- |
| 播放 | 点击列表播放按钮或底部播放按钮开始播放当前音频。 |
| 暂停 | 播放中点击暂停按钮，音频停留在当前进度。 |
| 切换音频 | 点击其他音频后，停止上一条并从新音频 0 秒开始播放。 |
| 进度 | 播放过程中实时更新当前时间和进度；用户可拖动进度条跳转。 |
| 播放结束 | 未开启循环时播放结束并停留在末尾；不自动播放下一条。 |
| 单曲循环 | 点击循环按钮开启/关闭单曲循环；开启后当前音频结束时从 0 秒重新播放。 |
| 状态同步 | 列表播放态、底部按钮、进度和当前音频信息必须同步。 |
| 页面返回 | 返回优学中心时暂停播放；再次进入 FM 时按产品实现保留列表筛选状态，播放不自动恢复。 |

## 7. 内容与资源规则

### 7.1 课内音频资源强约束

1. 课内音频仅包含 L1、L2 两个级别。
2. 保持现有课内资源不变，包括但不限于：
   * 音频文件与播放地址；
   * 标题、封面、字幕；
   * L1/L2 级别标记与适龄信息；
   * 资源排序、上下架状态、播放量及业务 ID；
   * 资源与课程、单元或内容标签的既有关系。
3. 本需求只读取和展示现有资源，不执行数据迁移、批量改写或重新上传。
4. 如果现有资源缺少 FM 展示所需字段，优先通过展示层兜底或建立只读映射，不回写原资源。
5. 不得为了适配 FM 将课内资源复制为新资源，避免形成重复数据和多套资源 ID。

### 7.2 分类与标签规则

| 字段 | 规则 |
| --- | --- |
| `content_scope` | `in_class`（课内）或 `out_of_class`（课外）。 |
| `category` | ALL 为前端聚合态；资源实际分类为早读、哄睡、磨耳朵、唱儿歌、听故事、学英语、课内之一。 |
| `level` | 课内仅允许 `L1`、`L2`；课外沿用既有数据。 |
| `age_band` | 沿用现有年龄标签；同一资源可命中一个年龄段。 |
| 多标签处理 | 如现有资源拥有多个课外场景标签，可在相应分类中重复出现，但列表内同一资源不得重复。 |

## 8. 状态、异常与兼容性

| 场景 | 产品表现 |
| --- | --- |
| FM 页面加载中 | 展示轻量加载状态，不允许重复触发入口。 |
| 列表为空 | 展示“暂时没有符合条件的音频”，保留筛选与分类入口。 |
| 列表加载失败 | 展示“加载失败，请重试”，支持原地重试。 |
| 音频播放失败 | 停止加载态并提示“播放失败，请稍后重试”；其他音频仍可点击。 |
| 封面缺失 | 展示统一默认音频封面，不影响标题与播放。 |
| 标题过长 | 单行省略，完整标题可通过无障碍文本读取。 |
| 时长缺失 | 播放前显示 `--:--`；播放元数据加载后更新。 |
| 字幕缺失 | 提示“该音频暂未提供字幕”，不影响播放。 |
| 筛选参数失效 | 自动恢复「全部」并刷新列表。 |
| 课内出现 L3 及以上资源 | 前端不展示并记录异常；服务端不得返回。 |
| 网络切换 | 已缓冲内容按播放器能力继续；失败时提供重试，不自动跳转。 |
| 横屏适配 | 支持手机、Pad 横屏；列表、Dino、顶部筛选及底部播放器不得重叠。 |
| 点击热区 | 返回、筛选、分类、播放等热区与视觉控件一致，不得相互覆盖。 |
| 页面刷新 | 可独立加载 FM 首页，不依赖优学中心的前序状态。 |

## 9. 数据与接口要求

### 9.1 列表请求建议

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `category` | string | 是 | 默认 `all`；课内为 `in_class`。 |
| `filter_type` | string | 否 | `age` 或 `level`；未筛选时为空。 |
| `filter_value` | string | 否 | 年龄段或级别值；与 `filter_type` 配套。 |
| `page_no` | number | 是 | 页码。 |
| `page_size` | number | 是 | 每页数量。 |

### 9.2 音频返回字段建议

| 字段 | 说明 |
| --- | --- |
| `audio_id` | 音频唯一 ID，沿用现有资源 ID。 |
| `title` | 音频标题。 |
| `cover_url` | 封面地址。 |
| `audio_url` | 音频播放地址。 |
| `subtitle_url` / `subtitle_text` | 字幕地址或字幕内容。 |
| `duration` | 音频总时长，单位秒。 |
| `content_scope` | 课内/课外。 |
| `category` | 内容分类。 |
| `level` | 级别；课内只能为 L1/L2。 |
| `age_band` | 适龄范围。 |
| `play_count` | 播放量/收听量。 |

### 9.3 服务端校验

* 当 `category=in_class` 且 `filter_type=level` 时，`filter_value` 仅允许为空、`L1` 或 `L2`。
* 课内列表响应不得包含 L3 及以上资源。
* FM 查询不得修改原音频资源、排序及上下架状态。
* 接口返回重复 `audio_id` 时，服务端优先去重；客户端同时做防重复兜底。

## 11. 验收标准

### 11.1 入口与页面

* [ ] 优学中心右上角展示 FM 入口，点击后进入 FM 首页。
* [ ] FM 左上角返回按钮可返回优学中心，箭头在圆圈内准确居中。
* [ ] 手机与 Pad 横屏下，页面主体、列表、Dino、筛选入口和播放器无拉伸、遮挡或错位。

### 11.2 筛选

* [ ] 筛选默认展示「全部」。
* [ ] 年龄和级别通过左侧标签手动切换，不自动级联跳转。
* [ ] 两个维度全局互斥单选：选择年龄会清除级别，选择级别会清除年龄。
* [ ] 选中结果实时回填顶部筛选胶囊，再次打开时保留选中态。
* [ ] 点击筛选入口或面板外区域可关闭；点击面板内部不误关闭。
* [ ] 分类为课内时，级别仅展示「全部、L1、L2」。
* [ ] 课内列表中不出现 L3 及以上音频。

### 11.3 分类

* [ ] 分类入口默认展示「ALL」。
* [ ] 点击分类入口后按原型打开分类抽屉和蒙层。
* [ ] 点击分类项后完成真实切换、关闭抽屉并刷新列表。
* [ ] 点击抽屉外蒙层关闭抽屉；点击抽屉内部空白不关闭。
* [ ] 筛选胶囊与分类胶囊间距、尺寸和点击热区符合原型，互不覆盖。

### 11.4 播放与字幕

* [ ] 点击列表音频可真实播放，播放态与底部播放器同步。
* [ ] 播放、暂停、进度拖动及单曲循环均可正常使用。
* [ ] 切换音频后上一条停止，新音频从 0 秒播放。
* [ ] 点击 Dino 可显示/隐藏字幕；切换音频后字幕内容同步更新。
* [ ] 无字幕、播放失败及网络异常均有明确反馈且不阻塞其他操作。

### 11.5 资源一致性

* [ ] 上线前后现有课内 L1、L2 音频资源数量一致。
* [ ] 现有课内音频的 ID、标题、封面、音频、字幕、级别、年龄、排序及上下架状态均未改变。
* [ ] FM 仅聚合读取现有课内资源，不产生重复资源 ID 或新的资源副本。
* [ ] 原有资源入口及播放能力不受 FM 上线影响。

## 12. 上线与回归范围

### 12.1 上线前检查

* 核对课内 L1、L2 资源清单、数量和字段快照。
* 检查课内查询接口不会返回 L3 及以上资源。
* 检查所有原型点击热区、蒙层层级和横屏适配。
* 在至少一台手机横屏和一台 Pad 横屏设备完成播放、筛选、分类、字幕和返回回归。

### 12.2 上线后观察

* 关注 FM 入口点击率、音频播放成功率、播放完成率和字幕使用率。
* 监控课内 L3 及以上资源误返回、资源重复、音频地址失效和字幕缺失异常。
* 对比上线前后既有课内资源数量及核心字段，确认无数据变更。
