## 1. 需求背景

优学 App 首页包含 AI 探险课程、双师智学课程、拓展课程、会员权益、FM、学习记录等多个功能。新用户首次进入时，难以快速理解各一级页面的定位及核心入口，可能出现功能发现率低、入口误解和学习路径不清晰等问题。

本需求在四个一级 Tab 页面增加分步骤新手引导，通过蒙层、Dino 形象、引导文案、箭头及高亮区域，帮助用户快速认识主要功能入口。

为便于当前交互原型演示，**浏览器刷新后需要重新展示新手引导**。该规则仅用于演示环境；正式生产环境应按“用户 + 引导版本”控制展示频次。

## 2. 产品目标

1. 帮助首次使用用户理解四个一级 Tab 的功能定位。
2. 提升探险课程地图、继续学习、专属探险、学习记录、FM 等入口的发现率。
3. 帮助用户理解双师智学的定级测评、体验课和系统课学习路径。
4. 支持用户通过“下一步”连续浏览引导，也可随时“跳过”。
5. 保证引导点击区域足够大，适配手机与 Pad 横屏触控。
6. 支持刷新页面后重新演示完整引导流程。

## 3. 非目标

- 本期不新增或调整四个一级页面原有业务功能。
- 本期不修改课程、会员、FM、学习记录等业务数据。
- 本期不支持用户在个人中心主动重新打开某一套引导。
- 本期不建设后台可视化配置系统。
- 本期不支持运营动态修改引导文案、步骤和图片。
- 本期不包含竖屏适配。

## 4. 用户角色与使用场景

### 4.1 用户角色

- 新注册用户：首次进入优学 App，需要了解核心学习功能。
- 已注册但未使用新模块的用户：版本升级后首次进入对应页面。
- 产品、设计、研发及测试人员：刷新原型后重复演示和验收引导流程。

### 4.2 核心场景

- 用户首次打开优学中心，依次了解该页面的主要功能入口。
- 用户首次切换至双师智学，了解定级、体验课及系统课路径。
- 用户首次切换至拓展学习，了解拓展课程内容。
- 用户首次切换至会员订阅，了解会员套餐与权益。
- 用户不希望继续查看时，可点击“跳过”关闭当前页面全部剩余步骤。
- 演示人员刷新页面后，可重新从第一步开始演示。

## 6. 整体交互规则

### 6.1 触发时机

| 场景 | 触发规则 |
| --- | --- |
| App/原型首次打开 | 优学中心页面加载完成后，自动展示优学中心第 1 步引导 |
| 首次进入双师智学 | 页面主体资源加载完成后，展示双师智学第 1 步引导 |
| 首次进入拓展学习 | 页面主体资源加载完成后，展示拓展学习引导 |
| 首次进入会员订阅 | 页面主体资源加载完成后，展示会员订阅引导 |
| 同一次页面生命周期内再次进入 | 已完成或跳过的页面引导不重复展示 |
| 刷新交互原型 | 清空本次页面生命周期的引导状态；重新进入后再次展示引导 |

### 6.2 展示频次

| 环境 | 展示规则 |
| --- | --- |
| 当前交互原型/演示环境 | 每次刷新页面后重置；各一级页面首次进入时重新展示 |
| 正式生产环境 | 建议按 `user_id + guide_version + page_id` 记录；每个版本每个页面仅展示一次 |
| 未登录用户 | 建议按设备匿名 ID + 引导版本记录，登录后合并至账号状态 |

### 6.3 操作规则

1. **下一步**
   - 点击后进入当前页面引导的下一步骤。
   - 最后一步按钮文案为“我知道了”，点击后关闭引导。
   - 点击热区应覆盖视觉按钮，并向四周扩展至少 12 px。
   - 为避免触控不灵敏，引导蒙层非“跳过”区域也可点击推进下一步。

2. **跳过**
   - 点击后立即关闭当前页面的整套引导。
   - 当前页面剩余步骤不再展示。
   - 不影响其他一级页面首次进入时展示各自引导。

3. **页面切换**
   - 引导展示期间，蒙层下方页面不可操作。
   - 不允许通过蒙层误触原页面卡片、Tab、返回按钮或其他业务入口。
   - 切换至其他页面前，应先关闭当前引导层。

4. **返回与刷新**
   - 同一次页面生命周期内，完成或跳过后返回该页面不重复展示。
   - 浏览器刷新后，演示状态清空，再次从对应页面第 1 步展示。

## 8. UI 与适配要求

1. 引导图按页面可视区域完整覆盖，保持与底层页面一致的横屏比例。
2. 不应将手机外框、浏览器地址栏、黑色画布背景等演示容器元素重复覆盖到 App 页面内部。
3. 图片加载完成前不得短暂露出可操作的底层页面；可使用当前页面背景或占位色承接。
4. 引导层级高于页面卡片、底部 Tab、弹窗入口和浮层控件。
5. 图片不可拉伸变形；不同宽高比设备优先按安全区域等比适配。
6. 点击热区随图片同比例缩放，不使用固定像素定位。
7. 引导按钮获得焦点时，不显示额外白色轮廓；需保留无障碍语义标签。
8. 手机与 Pad 横屏均应保证“下一步”“跳过”“我知道了”可点击。

## 9. 状态与数据逻辑

### 9.1 状态定义

| 状态 | 说明 |
| --- | --- |
| `not_started` | 当前页面引导尚未开始 |
| `showing` | 当前页面引导正在展示 |
| `completed` | 用户完成最后一步 |
| `skipped` | 用户点击“跳过” |

### 9.2 建议状态结构

```json
{
  "guide_version": "v1",
  "pages": {
    "study": "completed",
    "smart": "skipped",
    "extension": "not_started",
    "vip": "not_started"
  }
}
```

### 9.3 原型演示状态

- 状态仅保存在当前页面内存中。
- 页面刷新后内存状态清空。
- 刷新后再次进入各一级页面，重新展示该页面引导。

### 9.4 正式环境建议

- 使用服务端或本地持久化记录 `guide_version`、`page_id` 和完成状态。
- 引导视觉或步骤发生明显变化时升级 `guide_version`，允许用户重新查看新版引导。
- 正式环境不得沿用“每次刷新重新展示”的演示逻辑。

## 10. 异常与兜底

| 异常场景 | 处理方式 |
| --- | --- |
| 引导图片加载失败 | 关闭当前引导并恢复底层页面交互，同时记录加载失败事件 |
| 下一张图片未加载完成 | 当前步骤保持展示；预加载成功后再允许切换，或展示轻量加载状态 |
| 用户连续快速点击 | 300 ms 内只响应一次，避免跳过多个步骤 |
| 点击按钮无响应 | 整个引导层作为“下一步”的兜底点击区；“跳过”区域优先识别 |
| 页面切换中触发引导 | 等待目标页面稳定渲染后再展示，避免图片与页面错位 |
| 横竖屏切换 | 本期仅支持横屏；若进入竖屏，暂停引导并提示旋转设备 |
| 业务弹窗同时触发 | 新手引导优先；引导关闭后再按业务优先级决定是否展示弹窗 |

## 11. 埋点需求

| 事件名称 | 触发时机 | 关键参数 |
| --- | --- | --- |
| `onboarding_guide_view` | 某一步引导曝光 | `guide_version`、`page_id`、`step_index`、`step_name` |
| `onboarding_next_click` | 点击“下一步” | `page_id`、`step_index`、`click_area` |
| `onboarding_skip_click` | 点击“跳过” | `page_id`、`step_index` |
| `onboarding_complete` | 点击最后一步“我知道了” | `page_id`、`total_steps`、`duration_ms` |
| `onboarding_image_load_fail` | 引导图片加载失败 | `page_id`、`step_index`、`error_code` |

### 11.1 上报规则

- 每一步实际进入可视区域后，上报一次曝光。
- 同一步因图片重绘或屏幕尺寸变化不得重复上报。
- 点击“跳过”后不上报完成事件。
- 原型刷新重播产生的事件应携带 `environment=prototype`，避免混入正式业务分析。
- 埋点中不记录用户姓名、手机号等个人信息。

## 12. 验收标准

### 12.1 功能验收

1. 首次打开原型，优学中心自动展示第 1 步引导。
2. 优学中心 6 张引导图顺序正确，点击“下一步”逐步切换。
3. 双师智学 4 张引导图顺序正确。
4. 拓展学习和会员订阅首次进入时分别展示单步引导。
5. 点击“跳过”后，当前页面剩余步骤立即关闭。
6. 完成或跳过后，同一次页面生命周期再次进入不重复展示。
7. 刷新页面后，引导状态重置并可重新演示。
8. 最后一步点击“我知道了”后关闭引导并恢复页面交互。

### 12.2 视觉验收

1. 图片与对应页面匹配，不串页、不重叠、不拉伸。
2. 优学中心第 1 步使用最新「优学中心tab引导」图片。
3. 不出现透明热区的白色焦点框或其他浏览器默认样式。
4. 蒙层下方所有业务入口不可误触。
5. 切换步骤时无明显白屏、闪烁或页面割裂。

### 12.3 触控验收

1. “下一步”“跳过”“我知道了”点击一次即可响应。
2. 热区覆盖视觉按钮并适当外扩，按钮边缘点击同样有效。
3. 手机及 Pad 横屏真机均无明显点击延迟。
4. 快速连续点击不会一次跳过两步及以上。

## 14. 上线与回滚

1. 引导图片作为静态资源随版本发布，并配置资源版本号避免缓存旧图。
2. 上线前完成手机与 Pad 横屏真机验收。
3. 正式环境需确认展示频次已切换为持久化规则，不得每次刷新重复弹出。
4. 建议增加远程开关：可按版本关闭全部引导或指定页面引导。
5. 若图片加载、点击穿透或业务弹窗冲突影响主流程，可通过远程开关关闭引导，不影响底层页面使用。

## 15. 待确认项

1. 正式上线是否按“每个引导版本仅展示一次”执行。
2. 未登录状态完成引导后，登录账号是否继承设备侧完成状态。
3. 是否在设置或个人中心增加“重新查看新手引导”入口。
4. 正式环境是否需要支持运营后台动态配置引导版本与开关。
