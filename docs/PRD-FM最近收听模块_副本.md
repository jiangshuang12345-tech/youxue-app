# 优学 App FM「最近」模块 PRD

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品 | 优学 App |
| 模块 | FM 音频功能 |
| 需求名称 | 最近收听记录 |
| 文档版本 | V1.1 |
| 更新日期 | 2026-11-24 |
| 适用端 | iOS、Android |

## 2. 需求背景

现有 FM 页面缺少统一的历史收听入口，用户无法快速找到近期听过的音频。为提升内容回访效率，在 FM 模块新增「最近」入口及独立列表页，并复用 FM 一级列表的视觉与播放交互。

## 3. 需求目标

1. 用户可从 FM 一级页面进入「最近」页面，查看近期收听过的音频。
2. 用户可在「最近」页面直接播放、暂停或切换历史音频。
3. 列表展示音频基础信息与历史收听人数，不展示个人收听时间。
4. 「最近」页面样式及交互与 FM 一级列表保持一致。

## 4. 用户流程

FM 一级页面 → 点击「最近」 → 进入最近收听列表 → 点击音频或播放按钮 → 播放对应音频 → 点击返回 → 回到 FM 一级页面。

## 5. 名词说明

| 名词 | 说明 |
| --- | --- |
| 最近 | 用户近期收听过的 FM 音频集合 |
| 历史收听人数 | 历史上收听过该音频的去重用户数 |
| FM 一级页面 | FM 模块首页，包含分类、筛选、音频列表及播放器 |

## 7. 数据规则

### 7.1 数据字段

| 字段 | 说明 | 展示/处理规则 |
| --- | --- | --- |
| audioId | 音频唯一 ID | 用于播放、去重及记录关联 |
| title | 音频名称 | 单行展示，超出省略 |
| coverUrl | 封面地址 | 加载失败使用默认封面 |
| level | 课程级别 | 示例：L1 |
| ageRange | 适龄范围 | 示例：0-3岁 |
| listenerCount | 历史收听人数 | 展示整数，示例：🎧 3413 |
| lastPlayedAt | 用户最近收听时间 | 仅用于排序，不在页面展示 |
| duration | 音频总时长 | 用于播放器展示与进度计算 |

### 7.2 历史收听人数统计口径

| 规则 | 说明 |
| --- | --- |
| 统计对象 | 历史上收听过该音频的用户数量 |
| 去重规则 | 按用户去重，同一用户多次播放只计 1 人 |
| 有效收听 | 音频开始播放即记为一次有效收听；如后台已有统一 FM 统计口径，则沿用后台口径 |
| 前端处理 | 前端仅展示接口返回值，不使用本地播放次数累加 |

### 7.3 最近记录规则

| 规则 | 说明 |
| --- | --- |
| 去重 | 同一音频仅保留一条记录 |
| 更新 | 用户再次播放同一音频后，更新 `lastPlayedAt` 并置顶 |
| 数量 | 建议最多保留最近 50 条，具体数量由服务端配置 |
| 未登录状态 | 可使用本地记录；登录后是否合并历史记录由后续版本评估 |

## 8. 埋点需求

| 埋点事件 | 触发时机 | 关键参数 |
| --- | --- | --- |
| fm_recent_entry_click | 点击「最近」入口 | userId、sourcePage |
| fm_recent_page_view | 「最近」页面曝光 | userId、recordCount |
| fm_recent_audio_click | 点击历史音频 | audioId、position |
| fm_recent_play_click | 点击播放/暂停 | audioId、action |
| fm_recent_back_click | 点击返回 | playingAudioId、playProgress |

## 9. 验收标准

| 序号 | 验收项 | 验收标准 |
| --- | --- | --- |
| 1 | 最近入口 | FM 一级页面存在「最近」入口，点击可进入独立页面 |
| 2 | 页面顶部 | 仅展示返回按钮和居中标题「最近」，不展示「ALL」 |
| 3 | 列表样式 | 卡片无外边框，样式与 FM 一级列表一致 |
| 4 | 列表排序 | 按最近收听时间倒序排列，同一音频不重复展示 |
| 5 | 信息展示 | 展示封面、名称、级别、适龄范围及历史收听人数 |
| 6 | 人数口径 | 页面不出现个人收听时间或“刚刚收听”文案 |
| 7 | 播放交互 | 播放、暂停、切换、拖动进度及循环功能正常 |
| 8 | 返回状态 | 返回 FM 一级页面后，当前播放状态和进度不丢失 |
| 9 | 异常兜底 | 空记录、封面失败、音频失败及人数缺失场景均正确展示 |
| 10 | 终端适配 | iOS、Android 横屏页面无重叠、裁切或点击区域偏移 |

## 10. 本期不包含

1. 最近记录的手动删除和批量清空。
2. 多设备历史记录实时同步。
3. 按时间、级别或年龄筛选最近记录。
4. 基于最近记录的个性化推荐。
