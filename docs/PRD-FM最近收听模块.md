# 优学 App FM「最近」模块 PRD

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品 | 优学 App |
| 模块 | FM |
| 需求名称 | 最近收听记录 |
| 文档版本 | V1.0 |
| 更新日期 | 2026-11-24 |
| 适用端 | iOS、Android |

## 2. 需求背景

现有 FM 页面缺少统一的历史收听入口，用户无法快速找到近期听过的音频。为提升内容回访效率，在 FM 模块新增「最近」入口及独立列表页，并复用一级列表的视觉与播放交互。

## 3. 需求目标

1. 用户可从 FM 一级页面进入「最近」页面，查看近期收听过的音频。
2. 用户可在「最近」页面直接播放、暂停或切换历史音频。
3. 列表展示内容基础信息与历史收听人数，不展示个人收听时间。
4. 页面样式及交互与 FM 一级列表保持一致。

## 4. 用户流程

FM 一级页面 → 点击「最近」 → 进入最近收听列表 → 点击音频或播放按钮 → 播放对应音频 → 点击返回 → 回到 FM 一级页面。

## 5. 功能需求

### 5.1 FM 一级页面

- 新增「最近」入口。
- 「最近」作为独立入口展示，不与音频分类混合。
- 点击后进入「最近」独立页面。
- 入口视觉、点击反馈与现有一级列表保持一致。

### 5.2 最近页面顶部

- 左上角仅保留「返回」按钮。
- 页面标题居中，文案为「最近」。
- 右上角不展示「ALL」或其他操作入口。
- 点击返回后，回到 FM 一级页面，并保留离开前的播放状态。

### 5.3 最近收听列表

- 按用户最近一次收听时间倒序排列，最近播放的内容排在最前。
- 列表样式与 FM 一级音频列表保持一致。
- 列表卡片不展示外边框；当前播放项不增加额外描边。
- 单条内容包含：
  - 音频封面；
  - 音频名称；
  - 课程级别；
  - 适龄范围；
  - 历史收听人数；
  - 播放/暂停按钮。
- 展示格式示例：`L1 · 0-3岁 · 🎧 3413`。
- 不展示“刚刚收听”“19:02”等个人收听时间信息。
- 音频标题过长时单行省略，不能挤压播放按钮。
- 列表支持纵向滚动。

### 5.4 播放交互

- 点击列表卡片或右侧播放按钮，播放对应音频。
- 当前播放项的按钮切换为暂停状态。
- 切换其他音频时，停止当前音频并播放新选择的音频。
- 播放区同步更新音频标题、总时长、当前进度和播放状态。
- 支持拖动进度条调整播放位置。
- 支持单曲循环切换。
- 点击 Dino 区域显示或隐藏字幕，行为与 FM 一级页面一致。

### 5.5 空状态与异常状态

- 无收听记录时展示空状态文案：“还没有收听记录，快去听听喜欢的内容吧”。
- 音频加载失败时提示：“音频加载失败，请稍后重试”。
- 封面加载失败时展示默认 FM 封面，不影响播放。
- 历史收听人数缺失时展示 `🎧 0`，不展示空值或异常字符。

## 6. 数据规则

| 字段 | 说明 | 展示/处理规则 |
| --- | --- | --- |
| audioId | 音频唯一 ID | 用于播放、去重及记录关联 |
| title | 音频名称 | 单行展示，超出省略 |
| coverUrl | 封面地址 | 加载失败使用默认封面 |
| level | 课程级别 | 示例：L1 |
| ageRange | 适龄范围 | 示例：0-3岁 |
| listenerCount | 历史收听人数 | 展示整数，示例：🎧 3413 |
| lastPlayedAt | 用户最近收听时间 | 仅用于排序，不在页面展示 |
| duration | 音频总时长 | 用于播放器展示与进度计算 |

### 6.1 历史收听人数统计口径

- 统计对象：历史上收听过该音频的用户数量。
- 统计维度：按用户去重，同一用户多次播放只计 1 人。
- 有效收听：音频开始播放即记为一次有效收听；如后台已有统一 FM 统计口径，则沿用后台口径。
- 前端仅展示接口返回值，不使用本地播放次数累加。

### 6.2 最近记录规则

- 同一音频仅保留一条记录。
- 用户再次播放同一音频后，更新其 `lastPlayedAt` 并置顶。
- 建议最多保留最近 50 条，具体数量由服务端配置。
- 未登录状态可使用本地记录；登录后是否合并历史记录由后续版本评估。

## 7. 埋点需求

| 埋点事件 | 触发时机 | 关键参数 |
| --- | --- | --- |
| fm_recent_entry_click | 点击「最近」入口 | userId、sourcePage |
| fm_recent_page_view | 最近页面曝光 | userId、recordCount |
| fm_recent_audio_click | 点击历史音频 | audioId、position |
| fm_recent_play_click | 点击播放/暂停 | audioId、action |
| fm_recent_back_click | 点击返回 | playingAudioId、playProgress |

## 8. 验收标准

1. FM 一级页面存在「最近」入口，点击可进入独立页面。
2. 顶部仅展示返回按钮和居中标题「最近」，无「ALL」。
3. 列表卡片无外边框，样式与一级列表一致。
4. 列表按最近收听时间倒序排列，同一音频不重复展示。
5. 每条记录展示封面、名称、级别、适龄范围及历史收听人数。
6. 页面不出现个人收听时间或“刚刚收听”文案。
7. 点击卡片或播放按钮可正常播放，切换音频、暂停、拖动进度和循环功能正常。
8. 返回 FM 一级页面后，当前播放状态和进度不丢失。
9. 空记录、封面失败、音频失败及人数缺失场景均有正确兜底。
10. iOS、Android 横屏页面均无重叠、裁切或点击区域偏移。

## 9. 本期不包含

- 最近记录的手动删除和批量清空。
- 多设备历史记录实时同步。
- 按时间、级别或年龄筛选最近记录。
- 基于最近记录的个性化推荐。
