# VIPKID 优学个人中心原型

基于需求截图制作的可交互静态原型，新增「我的课时」入口与课时详情二级页面。

## 本地预览

```bash
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000`。

## 功能

- 个人中心「我的课时」入口
- 双师智学课课时、双师智学体验课课时列表
- 剩余课时和精确到秒的有效期展示
- 可点击进入横版课时包有效期详情
- 可点击进入横版课时流水，并按获得、消耗、购买、赠送筛选
- 个人中心「我的订单」入口
- 横版订单列表、订单状态筛选和订单详情
- 首页与二级页面切换
- 桌面端和移动端响应式布局

课时展示数据位于 `script.js` 的 `lessonData` 中，可替换为接口返回数据。
